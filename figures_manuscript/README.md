# figures_manuscript — the final manuscript figures, one lean script each

Branch `manuscript-figures` exists so these scripts can be read top-to-bottom.
Every figure is generated by exactly ONE script here, named by its
**manuscript figure number**, and styled EXCLUSIVELY by
[`fluxpy/figstyle.py`](../fluxpy/figstyle.py) — the single styling file.

## Run

```bash
pixi run python figures_manuscript/fig06_flux_scatter.py   # one figure
pixi run python figures_manuscript/run_all.py              # all of them
```

Outputs land in `figures_manuscript/output/` as PDF + PNG. Copy them into a
dated `figures/YYYY_MM_DD/` folder of the manuscript repo to use them
(flipping the `\includegraphics` paths is a deliberate, explicit step).

## The style contract (why the figures look consistent)

- **Physical size.** Every figure is built at its REAL printed size for the
  Copernicus two-column layout: `fs.COL_W` = 8.3 cm, `fs.MID_W` = 12 cm,
  `fs.FULL_W` = 17 cm. The .tex must include them **without scaling**
  (`\includegraphics{...}` with no `width=`) — then the fonts print at
  exactly the size set in the style file.
- **One font size.** `figstyle.FONT_SIZE` (9 pt ≈ journal text size) is used
  for everything. To change every figure at once, edit that one constant.
- **One palette.** Flux-estimate colours come from `figstyle.C`, math-text
  labels from `figstyle.L` (single source: `fluxpy.naming`).
- Scripts contain **no styling**: no `rcParams`, no `fontsize=` arguments, no
  `bbox_inches="tight"` (a tight crop would silently change the physical
  width). Constrained layout is on by default.

## Tuning a figure

Adjust the `width=`/`aspect=` of `fs.figure(...)` in the figure's script —
nothing else. If text collides, make the figure taller, never the fonts
smaller.
