Reproduction

Leipzig Institute for Meteorology (LIM), Leipzig University

The repository contains the code and a locked Python environment, but no data: the first steps download the measurements from PANGAEA and every other input from a Zenodo data record (doi:10.5281/zenodo.23729591). A single command recomputes every data-derived number, table and figure of the paper and compares the numbers with the committed reference expected_numbers.txt.

Procedure¶

  1. Obtain the repository: on GitHub, Code → Download ZIP and unpack, or git clone https://github.com/FranzFlink/bacsam2-flux-analysis.git.

  2. Install pixi, which sets up the exact environment of the paper without modifying the rest of the system. The environment is locked for Windows, Linux and macOS.

  3. Run in a terminal in the repository folder (on Windows, enter cmd in the address bar of the Explorer window):

    pixi run all

    The first run downloads the environment (a few minutes), the published measurements (about 1.5 GB) and the Zenodo data record (about 0.2 GB); Figures 1, 4 and 5 download map data once. The run stops with an error if any number differs from the reference.

Individual steps can be run separately, for example pixi run numbers (numbers of the text), pixi run ec-quality (Appendix A), pixi run robustness and pixi run ec-bands (robustness checks), pixi run book (re-execute the chapters of this site), pixi run api (regenerate the API reference and the figure pages) and pixi run site (build this site into _build/html). The scripts page describes each step.
