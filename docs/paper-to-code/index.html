Printed numbers¶

No number in the paper is transcribed by hand. Every number of the text is printed by scripts/manuscript_numbers.py (text and Table 3) or scripts/ec_quality.py (Appendix A); the bodies of Tables 2, 4, C1 and A1 are written by scripts/make_manuscript_tables.py and scripts/ec_quality.py into tables_manuscript/. The output of the number scripts, together with that of the robustness checks, is committed as expected_numbers.txt; pixi run check fails if any number deviates from it by more than 0.02.
