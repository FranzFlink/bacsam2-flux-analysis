Leipzig Institute for Meteorology (LIM), Leipzig University

Each figure of the paper is produced by one script in figures_manuscript/ at its printed size, styled by fluxpy.figstyle (one font size, one colour per flux estimate). The pages show each figure with its caption from the paper, its construction, the code it depends on and the script itself. pixi run figures rebuilds all figures (about 3 minutes; Figures 1, 4 and 5 download map data once).
