fluxpy.figstyle

Leipzig Institute for Meteorology (LIM), Leipzig University

Paper: figure style and variable names · Source: fluxpy/figstyle.py

the single styling module of all manuscript figures.

All manuscript figure scripts (figures_manuscript/fig*.py) take their style from here only; no figure script sets rcParams, font sizes or colours itself.

Design contract

  1. Physical size. Figures are built at their printed size (Copernicus/AMT two-column layout on DIN A4). The .tex includes them without scaling (\includegraphics{...}, no width=), so fonts print at exactly the size set here. Widths:

    constantcmCopernicus figure class
    COL_W8.3one column (the default)
    MID_W12.01.5 columns
    FULL_W17.0full text width (two columns)

  2. One font size. FONT_SIZE is used for all text (labels, ticks, legends, annotations) and equals the journal text size. It is set here for the whole manuscript, never per figure.

  3. Exact width. save() writes without a tight bounding box, so the PDF keeps the exact physical width. Use layout="constrained" (the default from figure()) so nothing overflows.

Typical figure script:

from fluxpy import figstyle as fs
fs.apply()
fig, ax = fs.figure(width=fs.COL_W, aspect=0.8)
ax.plot(x, y, color=fs.C["H_obs_bulk"], label=fs.L["H_obs_bulk"])
fs.panel_label(ax, "(a)")
fs.save(fig, "fig06_flux_scatter")

def figure(width: float = COL_W, aspect: float = 0.75, **kwargs):
    """``plt.subplots`` at physical size: ``figsize=(width, width*aspect)``.

    Any extra kwargs (``nrows``, ``ncols``, ``sharex`` …) pass through.
    For a custom GridSpec layout use :func:`gridfig` instead — this function
    already creates axes, and adding a gridspec on top leaves a stray empty
    axes underneath that breaks constrained layout.
    """
    return plt.subplots(figsize=(width, width * aspect), **kwargs)

def gridfig(width: float = COL_W, aspect: float = 0.75, **kwargs):
    """Figure without axes at physical size, for ``fig.add_gridspec`` layouts.

    Constrained layout is on via the style, so ``add_gridspec`` +
    ``add_subplot`` compose cleanly::

        fig = fs.gridfig(width=fs.COL_W, aspect=1.7)
        gs = fig.add_gridspec(3, 4, height_ratios=[2, 1, 1])
        ax = fig.add_subplot(gs[0, 0])
    """
    return plt.figure(figsize=(width, width * aspect), **kwargs)

def panel_label(ax, label: str, x: float = -0.02, y: float = 1.02) -> None:
    """Bold panel letter '(a)' at the top-left corner, outside the axes."""
    ax.text(x, y, label, transform=ax.transAxes, fontsize=FONT_SIZE,
            fontweight="bold", va="bottom", ha="right")

def save(fig, name: str, png: bool = True) -> Path:
    """Save ``OUT_DIR/name.pdf`` (+ ``.png``) at the exact physical size.

    ``bbox_inches='tight'`` is deliberately not used: a tight crop changes the
    physical width and rescales the fonts in print.
    """
    OUT_DIR.mkdir(parents=True, exist_ok=True)
    pdf = OUT_DIR / f"{name}.pdf"
    fig.savefig(pdf, metadata={"Creator": "BACSAM-II figures_manuscript"})
    if png:
        fig.savefig(OUT_DIR / f"{name}.png")
    w, h = fig.get_size_inches()
    print(f"{name}: {w / CM:.1f} x {h / CM:.1f} cm  ->  {pdf}")
    return pdf
