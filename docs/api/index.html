API reference

Leipzig Institute for Meteorology (LIM), Leipzig University

All physics of the paper is in the Python package fluxpy. The scripts in scripts/ and figures_manuscript/ import it and write the numbers, tables and figures; the chapters of the Method section call the same functions. Each module names the section of the paper it implements, and each function that implements an equation quotes it in its docstring.

These pages are generated from the docstrings, signatures and #: comments of the code by docs/build_api.py (pixi run api); pixi run test fails if they are out of date. Each entry links to its source on GitHub and shows the source in a collapsible box.

Usage¶

from fluxpy.eddy_covariance import segment_flux          # one 5 km segment -> H, sigma_rand
from fluxpy.bulk import reference_config, compute_bulk_shf_obs
from fluxpy.sensitivity import skill_metrics              # slope, r, bias, RMSE against the EC flux

Conventions¶

  • Every flux is positive upward, from the surface to the atmosphere, in W m⁻². The model-diagnosed ERA5 and CARRA fluxes are sign-flipped once, in scripts/calc_bulk_and_ec_fluxes.py.

  • Physical constants are defined once, in fluxpy.util, with the values the paper states.

  • Temperatures may be passed in °C or K and pressures in hPa or Pa where a docstring says so; the helpers in fluxpy.util convert. Everything is computed in float64.

  • Variable names of the data files follow fluxpy.naming; the symbols are explained in the glossary.
