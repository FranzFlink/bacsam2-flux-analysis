Conventions

  • Every H_* is positive UPWARD (surface to atmosphere). The ERA5 and CARRA products are positive downward and are sign-flipped ONCE, in scripts/calc_bulk_and_ec_fluxes.py.

  • Diagnostics use the same pathway tokens: Ri_obs, Ri_rs, dtheta_obs, dtheta_rs, U_obs, U_era (dtheta = theta_air - theta_s). Every Ri_* is the two-point bulk Richardson number of Eq. (B3).

  • The segment file uses sensible_heat_flux for the EC flux; the pipeline output uses H_obs_ec.
